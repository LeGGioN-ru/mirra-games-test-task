# Часы с синхронизацией времени

Тестовое задание Mirra Games: часы, которые при запуске берут время с сервера, дальше идут сами и позволяют выставить время вручную.

**Демо:** https://leggion-ru.github.io/mirra-games-test-task/

## Что сделано

- При запуске время запрашивается с сервера, после этого часы идут локально без повторных запросов.
- Аналоговый циферблат с движущимися стрелками и текстовое время.
- Кнопка «Редактировать»: время выставляется перетаскиванием часовой и минутной стрелок или вводом с клавиатуры. После «Сохранить» часы идут от выставленного времени.
- Сцена часов загружается из локального бандла Addressables после явной инициализации Addressables, пока её грузят, показывается экран загрузки.
- Zenject (ProjectContext + сцены), UniTask, DOTween, сборка WebGL на GitHub Pages.

## Как устроен запуск

```
Bootstrap.unity (единственная сцена в Build Settings)
 └─ BootstrapFlow
     ├─ показать экран загрузки
     ├─ параллельно: Addressables.InitializeAsync  +  синхронизация времени
     └─ Addressables.LoadSceneAsync("Clock")  → прогресс на экране загрузки
Clock.unity (Addressable) → ClockSceneEntryPoint → экран загрузки плавно скрывается

ProjectContext (Resources, живёт всё время): часы, HTTP-клиент, цепочка источников времени,
загрузчик сцен, экран загрузки
```

Экран загрузки живёт в ProjectContext: сцена Bootstrap выгружается при загрузке Clock в режиме Single, а экран должен её пережить.

## Время с сервера

**Почему не Яндекс в браузере.** `https://yandex.com/time/sync.json` не отдаёт заголовок `Access-Control-Allow-Origin`, поэтому из браузера на github.io запрос блокируется политикой CORS (в редакторе и десктопной сборке CORS нет, там Яндекс работает). Поэтому источники выстроены в цепочку, своя для каждой платформы:

| Платформа | Порядок источников |
|---|---|
| WebGL | timeapi.io → time.akamai.com → заголовок `Date` своей страницы на github.io → часы устройства |
| Редактор, десктоп | yandex.com → timeapi.io → time.akamai.com → часы устройства |

- У timeapi.io и time.akamai.com CORS разрешён. Заголовок `Date` своей страницы читается как запрос к тому же домену, CORS ему не нужен. Для него добавлен параметр против кэша, а к времени прибавляются 0,5 с, потому что заголовок округлён до секунды.
- Если источник упал или не ответил за 5 секунд, берётся следующий. Часы устройства — последний вариант, в консоль тогда пишется предупреждение.
- Какой источник сработал, пишется в консоль браузера: `Clock synchronized with timeapi.io, round trip … ms`.

**Отсчёт без повторных запросов.** Запоминается опорная точка: время с сервера и `Time.realtimeSinceStartupAsDouble` в момент ответа. Текущее время = опорное время + прошедшее реальное время. `deltaTime` не суммируется: он зависит от `timeScale`, обрезается `maximumDeltaTime` и почти не идёт в фоновой вкладке. Поэтому часы не отстают, даже если вкладка долго была свёрнута.

**Почему без поправки RTT/2.** Первый и единственный запрос идёт по холодному соединению: DNS, TCP и TLS проходят до того, как сервер ставит метку времени. В замере RTT первого запроса был 3 с, и поправка RTT/2 делала часы на 1,44 с быстрее. Поэтому серверное время привязывается к моменту получения ответа: часы отстают на время доставки ответа, в замере это 0,17 с.

**Сон компьютера.** В браузерах на macOS, Linux и Android таймер страницы стоит, пока система спит. Раз в секунду часы сверяются с системными, и если те ушли вперёд больше чем на 2 с, это считается сном. На Windows таймер во сне идёт, поэтому там сверка выключена, чтобы ручной перевод системных часов не сбивал время с сервера.

**Часовой пояс** берётся из `TimeZoneInfo.Local`. В WebGL IL2CPP строит его через `localtime` Emscripten, который берёт смещение у браузерного `Date` для каждой даты, включая переходы на летнее время. `.jslib` для этого не нужен.

## Редактирование

- «Редактировать» замораживает на экране черновик текущего времени, сами часы продолжают идти. Редактируемые стрелки подсвечиваются.
- **Стрелки.** Над циферблатом лежит невидимая круглая зона нажатия. Стрелка выбирается по углу и расстоянию от центра. Изменение угла накапливается в минутах: 1° минутной стрелки = 1/6 минуты, 1° часовой = 2 минуты. Поэтому переход минутной через 12 меняет час, а полный оборот часовой переключает AM/PM. Время привязывается к целым минутам, секунды обнуляются.
- **Клавиатура.** Форматы `9:05`, `09:05:30`, а также без двоеточий: `930`, `0930`, `093015`. Неверное время подсвечивается красным, «Сохранить» тогда недоступна. Enter сохраняет, Esc отменяет.
- «Время сервера» возвращает синхронизированное время без нового запроса.

## Отрисовка и производительность

- Циферблат, риски, стрелки и колпачок рисуются кодом (наследники `MaskableGraphic`) со сглаживанием краёв через полоску затухающей альфы. Текстур нет, края гладкие при любом разрешении и без MSAA.
- Статичный циферблат и динамические стрелки с текстом лежат на разных Canvas, поэтому движение стрелок не перестраивает циферблат.
- Часовая и минутная стрелки обновляются раз в секунду. Секундная стрелка делает тик с отскоком: ease DOTween считается каждый кадр, без создания твинов. Между тиками трансформы не меняются.
- Цифровое время выводится через `TMP_Text.SetText` с форматом, без аллокаций, и только при смене секунды.
- Сборка: IL2CPP, Disk Size with LTO, модули DOTween без аудио и физики. Сжатие в Unity выключено, GitHub Pages сам отдаёт файлы через gzip. По сети грузится около 8,5 МБ.

## Структура

```
Assets/_Project/
  Scenes/                 Bootstrap (инициализация), Clock (Addressable)
  Scripts/
    Core/                 модель времени, синхронизация, математика стрелок, разбор ввода (без Unity UI)
    Infrastructure/       HTTP, источники времени, часы платформы, загрузчик сцен Addressables
    Presentation/         экран загрузки, отрисовка, представления и презентеры часов и редактирования
    Bootstrap/            инсталлеры Zenject, BootstrapFlow
    Editor/               стартовая сцена Play Mode, сборка WebGL
  Tests/Editor/           EditMode-тесты
Assets/Resources/ProjectContext.prefab
Assets/WebGLTemplates/Clock/  шаблон страницы на всё окно
```

Стек: Unity 2022.3.54f1, Zenject 9.2.0, UniTask 2.5.11, DOTween Pro, Addressables 1.22.3, TextMesh Pro 3.0.7.

## Тесты

129 EditMode-тестов на модель времени, синхронизацию, источники времени, математику стрелок, перетаскивание и разбор ввода. Запуск: Window → General → Test Runner → EditMode → Run All.

## Сборка и деплой

1. Меню **Build → WebGL** собирает проект в `Builds/WebGL`, контент Addressables собирается вместе с игрой.
2. Содержимое `Builds/WebGL` и пустой файл `.nojekyll` публикуются в ветку `gh-pages`.

Play Mode в редакторе всегда стартует со сцены Bootstrap, какая бы сцена ни была открыта.

## Ограничения

- Если все серверы недоступны, часы идут от времени устройства, об этом пишется предупреждение в консоль.
- Старый адрес timeapi.io (`/api/Time/current/zone`), у которого включён CORS, отсутствует в текущей документации сервиса. Если его уберут, сработают следующие источники.
- На macOS, Linux и Android ручной перевод системных часов вперёд больше чем на 2 с будет принят за сон компьютера.
